隱私權政策

生效日期：2026-10-15

本服務經營者（以下稱「我們」）重視你的隱私。本政策說明「德州撲克入門練習器」如何處理資料。簡單說：沒有註冊帳號、沒有廣告追蹤，學習資料留在你自己的裝置上；只有在你購買完整版時，才會處理訂單所需的最少資料。

1. 存放在你裝置上的資料（我們不會收到）

本服務使用瀏覽器的 localStorage 與 Service Worker 快取，在你的裝置上保存：

內容用途
課程進度、測驗結果、練習統計、每日任務顯示進度與統計
手牌歷史、模擬對戰設定手牌複盤與延續設定

今日免費對戰手數免費版每日手數限制
網頁程式與圖示的快取支援離線使用與安裝成 App

這些資料不會上傳到我們的伺服器。清除瀏覽器資料或解除安裝 App 即會刪除。

2. 網站託管與連線紀錄

本網站目前由第三方靜態網站託管服務（例如 GitHub Pages）提供。託管服務可能為了安全與營運而記錄連線資訊（例如 IP 位址、瀏覽器類型、造訪時間），我們無法取得你的個別瀏覽紀錄。本站目前未使用 Google Analytics 等行為分析或廣告追蹤工具；若日後加入，會在本政策更新並說明。

4. 使用目的與法律依據

我們僅在下列目的範圍內處理資料：完成交易與授權、客戶服務與退款、依法令保存帳務憑證、處理資安與濫用問題。我們不會把你的資料出售給第三方，也不會用於與上述目的無關的行銷。

5. 保存期間

交易與帳務資料依稅務與會計法令保存（一般為數年，以法令規定為準）；客服對話資料於處理完畢後保留合理期間（原則上於案件處理完畢後一年內）。期間屆滿後刪除或去識別化，法令另有規定者從其規定。

6. 第三方服務

  • LINE（LINE Corporation／LINE 台灣）：訊息溝通。
  • 金流服務商（例如綠界科技）：處理付款。
  • 雲端運算與儲存服務（例如 Cloudflare）：執行購買與授權流程所需之程式與訂單資料儲存。
  • 靜態網站託管（例如 GitHub Pages）：提供網站。

各服務商依其自身隱私政策處理資料。資料可能在境外伺服器處理；我們會要求合理的安全措施。

7. 你的權利

依《個人資料保護法》，你得就我們持有的你的個人資料請求：查詢或閱覽、製給複製本、補充或更正、停止蒐集處理利用、刪除。請以下方聯絡方式提出，並提供訂單編號以便確認身分。若依法令或交易需要保存者，我們會說明無法刪除的原因。

8. 未成年人

本服務為教學練習用途，不含真錢賭博。未成年人購買完整版應取得法定代理人同意。

9. 資料安全

授權簽章金鑰與金流金鑰僅存放在受保護的伺服器環境，不會出現在網站程式中。我們採取合理的技術與管理措施保護資料，但網際網路傳輸無法保證絕對安全。
